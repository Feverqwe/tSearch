# tSearch

Torrents MultiSearch — браузерное расширение для поиска по нескольким торрент-трекерам. Источники можно группировать в профили поиска. Для внешних трекеров используются [описания JSON](external/).

В конструкторе трекеров открой страницу выдачи и нажми «Определить поля». Расширение локально разберёт страницу, проверит результат и заполнит поля для дальнейшего редактирования. Если поисковый запрос или формат значений определить не удалось, конструктор покажет, что нужно проверить вручную.
