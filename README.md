# TMS — Поиск торрентов

TMS ищет торренты сразу на нескольких выбранных трекерах и показывает результаты в одном месте. Запросы отправляются напрямую на сайты трекеров.

## Как начать

Запустите поиск с панели Chrome или через контекстное меню выделенного текста. На странице поиска можно выбрать список трекеров.

- Фильтруйте результаты по словам, дате, размеру, числу сидов и личеров. Сортируйте раздачи по качеству и настраивайте правила оценки.
- Просматривайте подборки фильмов, сериалов и игр и запускайте поиск из карточек.
- Возвращайтесь к предыдущим запросам через историю. Резервную копию данных расширения можно сохранить и восстановить в формате ZIP.

Для установки из исходников воспользуйтесь [руководством по сборке и запуску в Chrome](docs/development.md).

## Свои трекеры

Можно подключить [готовое описание JSON](external/) или [создать свой трекер по пошаговой инструкции](docs/create-tracker.md).

Редактор трекеров также позволяет вручную импортировать скрипт `.user.js`. Для его запуска требуется подтверждение пользователя. Сетевой каталог и автообновление работают с описаниями JSON.

## Данные поиска

История поиска хранится локально. Для автодополнения введённый текст отправляется сервису подсказок Google. Настройки, списки трекеров и избранное могут синхронизироваться через Chrome Sync.
