# Агентский контекст

Из корня репозитория запусти:

```sh
sh .agents/scripts/setup-context.sh
```

Скрипт создаёт локальный каталог `.codex/`. Начни с `.codex/Home.md`. Каталог можно открыть как хранилище Obsidian. Повторный запуск сохраняет существующие файлы. У каждого checkout свой локальный каталог.

## Как читать и обновлять память

- Начинай с [AGENTS.md](../AGENTS.md). При продолжении работы читай `.codex/notes/handoff.md`, если он есть. Для прошлых расследований ищи точечно через `rg --no-ignore --hidden <запрос> .codex/notes`.
- Для передачи незавершённой работы используй шаблон `.codex/templates/handoff.md`. Запиши цель, подтверждённые наблюдения со ссылками, сделанные проверки и следующий шаг. По завершении задачи убери устаревшие указания из файла передачи.
- Рабочие записи храни в `.codex/notes/`, при необходимости сохраняй экспорты переписок в `.codex/dialogs/`. Для публичной документации переноси проверенные инструкции и действующие контракты.

Правило `/.codex/` в [`.gitignore`](../.gitignore) распространяется на весь каталог. Перед публикацией проверяй содержимое индекса Git и историю публикуемых веток. Правило исключения действует на неотслеживаемые файлы.
