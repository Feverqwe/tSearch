# Контракт ExKit

ExKit — LTS-интерфейс, через который расширение исполняет встроенные и внешние описания трекеров. JSON формата v3 может передаваться между версиями расширения через каталог, экспорт или резервную копию. Сохраняй смысл существующих операций, их аргументов и выходных значений. Исправление поведения оценивай на сохранённых описаниях. Изменения, требующие нового контракта, обсуждай отдельно с учётом версии формата и миграции.

Каталоги и автоматические обновления принимают JSON v3. Пользователь может загрузить JavaScript-трекер вручную и подтвердить выполнение конкретной версии. Скрипт выполняется в песочнице и может отправлять запросы к origin, указанному в `@trackerURL`. Резервная копия переносит скрипт, а разрешение на выполнение выдаётся отдельно при импорте. [Установка скрипта](development.md#проверка-и-ремонт-трекеров).

Конструктор использует модель и тулкит исследования HTML, чтобы собрать JSON из совместимого набора операций ExKit v3. Расширяй инструменты исследования независимо от операций, исполняемых при поиске. Если тулкит нашёл значение, для которого нет переносимого правила, конструктор может показать находку для ручной настройки.

После изменения ExKit проверь в конструкторе генерацию JSON с текущими весами и исполнение этого JSON штатным парсером. Возьми контрольные страницы с затронутым поведением. Сравни значения полей и количество разобранных строк с эталоном. Если правка затрагивает запрос, вход или пагинацию, проверь и этот сценарий. Отдельно проверь сохранённое описание, использующее изменённую операцию.

Решение о переобучении принимай по результатам проверки. Если исправилось исполнение готовых правил и текущие веса проходят проверку, оставь их. Если изменились признаки, набор кандидатов или разметка, сравни качество на затронутых примерах с контрольным набором. Переобучай затронутую модель, когда текущие веса выбирают неверный кандидат или пропускают корректный. Если нужного кандидата нет, сначала исправь тулкит или построение правила. Сравни новые и прежние веса на одном контрольном наборе вне обучения.
