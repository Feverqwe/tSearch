# tSearch для разработки

## Карта проекта

| Область задачи | Где начать |
| --- | --- |
| Основное окно, всплывающая панель, маршруты и страницы | [Приложение](../src/App.tsx), [панель](../src/Popup.tsx), [маршруты](../src/routes.tsx), [страницы](../src/pages/) |
| Поиск, настройки, профили и история | [Запросы и сохранение данных](../src/data/), [локальное состояние поиска и профилей](../src/stores/) |
| Встроенные источники и каталог внешних описаний | [Трекеры](../src/trackers/), [модули витрины](../src/explorerModules/), [внешние описания](../external/) |
| Фоновые операции, запросы через вкладки и изоляция модулей | [Фоновый код](../src/background/), [скрипт вкладки](../src/tabFetch.ts), [sandbox](../src/sandbox/) |
| Разрешения, точки входа расширения и переводы | [Манифест](../src/manifest.json), [локали](../src/_locales/) |

Основная страница и панель используют React Query для сохранённых данных и сетевых запросов интерфейса. MobX хранит состояние текущего поиска, фильтров и черновиков профилей.

Фоновый код работает в service worker Manifest V3. Встроенные модули поставляются вместе с расширением и выполняются в изолированном контексте. Для внешних трекеров действуют правила импорта из [контракта ExKit](exkit.md).
