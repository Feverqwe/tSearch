# Tracker Toolkit

Тулкит исследует HTML страниц торрент-трекеров. Конструктор использует его, чтобы найти кандидатов для строк и полей выдачи, восстановить шаблон поискового запроса, распознать страницу входа и найти следующую страницу. Модель ранжирует кандидатов, а выбранные правила входят в описание трекера формата ExKit v3.

Точка входа пакета — [`src/index.ts`](src/index.ts). Для исследования страницы передай HTML и конечный URL. Если известны исходный запрос или его тело, их можно передать вместе с HTTP-статусом.

```ts
import {inspectPage} from './packages/tracker-toolkit/src/index.ts';

const page = inspectPage(html, 'https://tracker.example/search?q=linux', 200, {
  phrase: 'linux',
});
```

Исследование выполняется в браузерной среде на переданном HTML. При обычном поиске расширение исполняет сохранённое описание через ExKit. Если для найденного значения нет переносимого правила, конструктор может показать его для ручной настройки. [Контракт ExKit и проверка модели](../../docs/exkit.md).

Проверки пакета можно запустить из корня репозитория:

```sh
node --test "packages/tracker-toolkit/src/__tests__/*.test.ts"
```
