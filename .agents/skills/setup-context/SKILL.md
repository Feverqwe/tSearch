# Настройка контекста tSearch

Открой `docs/agent-context.md` и запусти указанную там команду из корня репозитория. Проверь доступность `.codex/Home.md`. При конфликте пути сообщи, какой локальный файл или каталог требует внимания. Скрипт сохраняет локальные заметки, поэтому его можно повторить.
